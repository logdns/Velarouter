# Velarouter 介绍

Velarouter 是局域网优先、无需账号的开源加密远程桌面。主控和被控电脑安装同一个桌面客户端。在被控电脑开启共享后，把联机码和当前密码交给可信的人；需要结束访问时，在被控端停止共享。

## 连接模式

| 场景 | 操作 | 网络路径 |
|---|---|---|
| 同一局域网 | 主控输入被控端显示的局域网联机码与密码 | 直接连接被控电脑，无需公网或服务器 |
| 不同网络 | 输入互联网联机码与密码；使用自建信令时先配置服务地址 | 默认会合后 QUIC 点对点直连；失败会报错，不会自动切换中继 |
| 手机临时操作 | 在同一可信局域网打开被控端提供的 Web 地址，输入密码 | 浏览器连接被控端内置的 Web 服务；不是项目网站提供的主控 |

桌面只接收原有联机码，不输入 `IP:端口`。联机码不是身份或凭证。VRP/1 加密会话的威胁模型和自建服务的信任边界见[安全说明](SECURITY.md)，不要将被控端网页端口直接暴露到公网。

## 客户端与能力

- **桌面**：macOS Apple Silicon、Windows x64、Linux x86_64 / ARM64。画面、键鼠、文本剪贴板、多屏、在指定共享目录内收发文件。0.1.2 加入最近连接、可选可信设备限制和四路只读桌面墙。权限依赖操作系统；见[桌面指南](clients/DESKTOP-APP.md)。
- **Web**：随被控端提供，支持局域网浏览和操作；0.1.2 改善窄屏与单指操作。与桌面能力不同，不是原生 iOS / Android 应用。
- **终端与 CLI**：0.1.2 的 `velarouter-view` 可在 ANSI 终端只读预览；`velarouter` 提供探测、抓帧、文件传输及运维等命令。两者随安装包分发，见[终端指南](clients/TERMINAL.md)。

Linux 音频与 H.264 软件编解码为可选源码试验；标准安装包不包含这两项。尚未验收的功能不视为现有支持，详见[功能与状态](FEATURES.md)和[路线图](ROADMAP.md)。
