# 功能路线图

本页是讨论稿，不是版本承诺。已发布能力见[功能清单](FEATURES.md)。

## 先做：连接与信任

| 优先级 | 功能 | 验收标准 |
|---|---|---|
| 0.1.2 | 最近连接 | 成功认证后保存设备名与原联机码，按局域网和互联网分组，可移除。选择记录只填联机码，不保存密码也不自动连接 |
| 0.1.2 | 可信设备（可选） | 启用后校验密码及主控设备签名。可核对指纹、移除设备；旧桌面版、Web 和 CLI 在限制开启时不能连接 |
| P0 | 发布验收 | 验证同网离线直连、桌面双向连接、系统权限拒绝时的仅观看，以及跨 NAT 失败时的明确提示 |

## 再做：画面与更多主控入口

| 优先级 | 功能 | 验收标准 |
|---|---|---|
| 试验版，待跨平台验收 | H.264 软件编解码 | 非默认构建；仅支持的桌面两端启用，JPEG 保持兼容；验证关键帧恢复与 1080p/30 fps 上限 |
| Linux 试验版，待双机验收 | 远端音频 | 两端启用构建开关；被控端允许、主控端开启，默认静音。只采默认输出设备的监视源；未授权或无设备时画面不受影响 |
| 0.1.2，待真机验证 | 手机浏览器主控 | 支持窄屏工具栏、单指点击／拖动、等比缩放与断线提示；需要 iOS Safari 和 Android Chrome 双机实测，再决定是否开发原生主控 |
| 0.1.2 | [终端只读预览](clients/TERMINAL.md) | 复用既有联机码和认证；ANSI 字符画面可独立构建，不发送键鼠、不保存画面。Kitty／Sixel 和局部缩放为后续候选 |
| 0.1.2，四路 Xvfb 自动化已通过 | 桌面墙 | 四路画面更新与离开时释放会话已验证；仍需实机和跨网带宽验收。首版不群控、不批量分发文件 |

## 后续评估
- **部署**：优先衡量显式可选中继的实际需求。Windows 登录前、Linux 独立虚拟桌面另行验收，不等同于开机自启。
- **媒体**：AV1、HEVC 与硬编逐平台测试。若允许修改远端显示模式，必须由用户确认，并验证退出后恢复。
- **本机集成**：只评估用户可见、可撤销的只读预览，不将自主操作远端电脑纳入首版。

不做未经许可的静默监控。不把基础连接绑定到账号、付费云服务或全新媒体协议。
