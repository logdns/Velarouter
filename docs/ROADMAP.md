# Roadmap

> 版本目标：**v0.1 局域网可用** → **v0.2 公网可用** → **v0.3 多端完整**。
> 每一项都标注“验收标准”，避免“做完了但不能用”。

---

## v0.1 — 局域网可用（当前）

- [x] VRP/1 协议（JSON 控制 + 24B 媒体头）
- [x] P-256 ECDH + HKDF + AES-256-GCM
- [x] WebSocket 直连 + 配对码
- [x] 屏幕采集 + JPEG 编码 + 感知哈希跳帧
- [x] 鼠标/键盘/滚轮/触摸注入
- [x] 剪贴板双向
- [x] 浏览器客户端（WebCrypto）
- [x] 信令服务器（注册/配对/会话/中继）
- [x] 局域网发现、mini-STUN、UDP 打洞原语
- [x] CLI（signal/agent/probe/ls/get/put/wol/discover/doctor）
- [x] 文件传输（列目录 / 上传 / 下载 / 断点 / SHA-256 / 路径沙箱）
- [x] 多显示器列表与切换
- [x] Wake-on-LAN
- [x] 互联网 P2P：联机编码 + 密码 + UDP 打洞 + QUIC（无中继）
- [x] 桌面客户端初版：打开即被控（自动编码/密码）+ 远程协助
- [x] macOS `.app/.dmg`、Windows `.exe/.zip`、Linux 可编译
- [x] 单元测试 46 个，端到端实测（画面 / 文件 / 双加密后端）

**验收**：同一局域网，无外网，`agent` + 浏览器 3 分钟内看到画面并操作。

## v0.2 — 公网可用

- [ ] **UDP 媒体通道**
  - `FragmentHeader`/`Reassembler` 已就绪
  - 发送调度：按帧优先级、关键帧优先
  - 前向纠错：XOR 或 Reed-Solomon（每 10 包 2 冗余）
  - NACK：接收端请求缺失分片
  - 带宽估计：基于 RTT/丢包的 AIMD
  - 验收：20% 丢包下 1080p30 仍然可用（有损但连续）
- [x] **多显示器（切换）**
  - `DisplayList` + `display` 字段已支持
  - Web UI 下拉切换，Agent 实时生效
- [ ] **多显示器（并发）**
  - 每个显示器独立编码器
  - 主控端分屏/标签页
- [ ] **音频**
  - `Capabilities.audio = true`
  - Opus 采集/播放
  - 回声消除（可选）
- [x] **文件传输（核心）**
  - 独立 `kind=3` 文件通道
  - 断点续传 + SHA-256 + 临时文件原子替换
  - 目录浏览、路径沙箱
- [ ] **文件传输（增强）**
  - 目录递归、传输队列、限速
  - FUSE 只读挂载（剪贴板文件）
- [ ] **会话管理 UI**
  - 设备列表、最近连接、会话中状态
  - 主控端“正在被谁控制”提示

**验收**：跨运营商，两台 NAT 后的机器，30 秒内建立会话，1080p 可交互。

## v0.3 — 多端完整

- [ ] **硬件编码**
  - Windows：Media Foundation / NVENC / QSV / AMF
  - macOS：VideoToolbox（H.264/HEVC）
  - Linux：VAAPI / NVENC
  - Android：MediaCodec
  - 编码能力探测 + 自动回退
- [ ] **五端客户端**
  - Windows / macOS / Linux（MyGo 或 Tauri）
  - iOS（主控端 + ReplayKit 只读）
  - Android（主控 + MediaProjection 被控）
- [ ] **终端**
  - PTY 复用（tmux 风格）
  - 与桌面会话共享房间
- [ ] **虚拟按键 / 宏**
  - 客户端本地功能，协议只发最终输入
- [ ] **隐私屏**
  - 被控端本地显示遮罩，主控端仍可见
- [ ] **远程开机**
  - 局域网辅助节点（手机）
  - Wake-on-LAN

**验收**：五端互连矩阵全部通过；iOS/Android 通过商店审核。

## 技术债与已知缺口

| 项 | 影响 | 计划 |
|---|---|---|
| 无 UDP 媒体 | 公网延迟高 | v0.2 |
| 无硬件编码 | CPU 占用高 | v0.3 |
| 无音频 | 功能缺失 | v0.2 |
| 会话表在内存 | 重启丢设备 | v0.2（落库） |
| 无速率限制 | 可被爆破 | v0.2（反代或内置） |
| `video_config` 的 fps/分辨率不即时生效 | 需重连 | v0.2 |
| 无多会话并发上限 | 资源耗尽风险 | v0.2 |
| 无 iOS 输入注入 | 平台限制 | 不做 |
| JPEG 每帧全量 | 带宽高 | v0.2 分块/增量 |

---

## 明确不做

- 云电脑编排（属于 IaaS，不是远程桌面框架）
- 会员计费 / 活动运营
- 游戏反作弊对抗
- 任何形式的静默监控（必须由被控端用户显式授权）
