# 桌面使用指南

## 安装

从 [GitHub Releases](https://github.com/logdns/Velarouter/releases/latest) 下载。安装包的 SHA-256 在同一发布页的 `SHA256SUMS.txt` 文件中。

| 系统 | 操作 |
|---|---|
| macOS Apple Silicon | 打开 DMG，拖入「应用程序」。此包未公证；若系统阻止，请先核对下载来源与校验值，再到「隐私与安全性」查看系统提示。 |
| Windows x64 | 解压后运行 `Velarouter.exe`。这是未签名的便携版。 |
| Linux x86_64 / ARM64 | Ubuntu / Debian 优先安装对应架构的 `.deb`，再从应用菜单启动。若使用 `.tar.gz`，解包后运行 `./install.sh` 安装到当前用户（无需 sudo）。 |

Ubuntu / Debian 可使用系统安装器，也可在下载目录执行（ARM64 示例）：

```sh
sudo apt install ./Velarouter-0.1.3-linux-arm64.deb
```

x86_64 请选文件名带 `amd64` 的包。安装后从应用菜单搜索「Velarouter」，再固定到 Dock；若之前固定了旧图标，请先取消固定。解压目录中的裸可执行文件由文件管理器显示通用图标，不影响安装后的品牌图标。若以前用 tar.gz 的脚本安装过，升级时重跑新版脚本，以更新优先级更高的用户入口。

## 连接

1. **被控端**：在「本机共享」复制联机码和连接密码。两台机器在同一网络时，优先用「局域网」里的 `VR-…` 码。
2. **主控端**：在「连接电脑」输入两项，点击「连接」。窄窗口可以直接通过顶部页签切换，不用滚动寻找表单。
3. 连上后点击远程画面，再输入键盘内容。被控端可随时点「停止共享」。

0.1.3 的「连接电脑 → 最近连接」只记录认证成功的设备名和联机码，按局域网、互联网分组。选中记录后仍需输入密码；记录可逐条移除。

「互联网联机已就绪」表示会合服务在线，不代表任意两台设备都能跨网直连。跨网失败时优先试局域网码，再检查防火墙、UDP 和 [NAT 限制](../RENDEZVOUS.md)。默认不会自动切换到中继。

## 手机浏览器主控

让手机和被控电脑连到同一可信局域网，用手机浏览器打开被控电脑的局域网页面（通常是 `http://<被控电脑局域网地址>:34789/`），输入被控端显示的连接密码。此网页入口不改变桌面端的联机码；GitHub Pages 不是远控入口。

轻点画面相当于鼠标左键；按住单指拖动。默认等比适应窗口。「原始尺寸」可在本地滚动画面细节，此模式不会发送远端操作；点「返回操控」恢复。全屏按钮只在浏览器支持时显示。暂不支持多指手势或原生手机应用。页面不会保存密码；断线后需重新输入。启用可信设备限制的被控端仍需已配对的桌面主控。

## 可信设备（0.1.3 起）

默认关闭；不改变原有联机码，也不能代替连接密码。两台电脑都需使用支持可信设备的桌面版本。

1. 在**主控端**打开「设置 → 权限 → 可信设备」，点击「复制本机配对信息」。通过可信渠道发送，配对信息只含公钥。
2. 在**被控端**打开同一位置，粘贴配对信息并添加；点击名单中的指纹可复制完整指纹，与主控端显示的指纹核对。
3. 在被控端启用「仅允许可信设备连接」。主控端仍用原联机码和密码连接。

启用、关闭或更改生效中的名单会重启本机共享并断开现有会话。名单为空时拒绝所有远程连接。旧桌面版、浏览器和 CLI 无法连入开启限制的设备。可信关系是单向的，互控需分别添加。

## 桌面墙（0.1.3 起）

在首页「连接电脑」区域点「桌面墙 · 只读预览」，用对方的原联机码和密码逐台连接，可为每台设备指定分组。两端都需要使用 0.1.3 或更新版本；如果被控端启用了可信设备限制，主控仍需先完成配对。

最多 4 个预览位，每路最高 480×270 / 3 fps。筛选分组只改变显示，隐藏的预览仍占用连接；放大也不提高分辨率或切换为远控。移除、返回首页、进入设置或关闭窗口都会停止对应预览。设备列表、密码和画面不写入磁盘，也不会自动重连。被控端仍显示会话接入提示，并可停止共享。

## Linux 远端声音（试验）

需要两台 Linux 电脑都使用[带 `linux-audio` 开关的构建](../BUILD.md#linux-系统声音试验)，并运行 PulseAudio 或 PipeWire 的 PulseAudio 兼容服务。被控端在「设置 → 权限」勾选「允许共享本机系统声音」；主控端连接后在会话底部点「开启声音」，可随时关闭。每次连接默认静音。

仅采集被控端默认输出设备的声音，不采麦克风。它可能包含不同应用和系统通知，不局限于当前共享的画面。去掉共享允许会重启本机共享并断开当前会话。网页、终端、macOS 和 Windows 不支持此试验功能。

## 显示、文件与启动

- 会话内点「显示设置」，按本机显示器、窗口或固定分辨率调整；网络慢时降低画质或帧率。
- 会话内点「文件」打开双栏窗口。左栏是本机，右栏是对方共享目录。可选文件或将文件拖入窗口排队上传。
- 中文输入使用主控端输入法，确认候选后才发送。
- 打包版默认开机自启并开始共享。在「设置 → 设备」关闭自启，或调整关闭窗口后是否继续共享。只需临时停止访问时点「暂停共享」。
- Linux 默认使用浅色。可在「设置 → 设备 → 界面主题」切换浅色、深色或跟随系统，选择会自动保存。macOS 和 Windows 默认跟随系统。
- 「设置 → 关于」提供项目地址和下载入口。

## 只能观看，不能操作

- **macOS**：被控端需要「屏幕录制」权限才能出画面，需要「辅助功能」权限才能接受键鼠。授权当前安装的 App 后退出重开。更新未公证的安装包后可能需要重新授权。
- **Windows**：普通窗口可以操作；锁屏、UAC 安全桌面等受系统限制。跨网没有响应时，到「设置 → 权限」检查 Windows 防火墙。
- **Linux X11**：在已登录的桌面会话里运行，不用 sudo。**Wayland**：在系统弹窗中选屏幕并打开「允许远程交互」。授权仅适用于选中的屏幕；拒绝或撤销后只能观看。重新申请会重启共享、断开现有会话。
