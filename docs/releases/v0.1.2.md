## Velarouter 0.1.2

- **桌面端**：最近连接只保存已认证设备的名称和联机码，不保存密码；新增可选可信设备名单。桌面墙支持最多四路分组只读预览，不可发送键鼠、剪贴板、文件或声音。桌面墙需要两端都升级。
- **局域网 Web**：改善手机窄屏、等比显示和单指操作；断开后重新输入密码。通过被控端提供的局域网页面使用，不是公开网站上的主控。
- **命令行**：安装包包含 `velarouter` 和 `velarouter-view`，分别用于诊断／运维及 ANSI 终端只读预览。可信设备限制开启时使用已配对的桌面客户端；Web 和终端不支持该认证。
- **连接方式不变**：沿用联机码和密码，局域网不依赖公网服务；跨网优先 QUIC，不自动中继。

默认安装包继续使用 JPEG，不包含 H.264 或 Linux 系统声音试验。真机 Wayland、iOS Safari / Android Chrome、跨 NAT 与四台实机并发仍需单独验收。

下载对应平台安装包和 `SHA256SUMS.txt` 核对文件。macOS DMG 是临时签名，未公证；Windows ZIP 解压运行。详见[使用指南](https://github.com/logdns/Velarouter/blob/v0.1.2/docs/clients/DESKTOP-APP.md)、[终端指南](https://github.com/logdns/Velarouter/blob/v0.1.2/docs/clients/TERMINAL.md)和[验收记录](https://github.com/logdns/Velarouter/blob/v0.1.2/docs/clients/LINUX-ACCEPTANCE.md)。
